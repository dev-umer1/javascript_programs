What is DOM in JavaScript?
DOM (Document Object Model) is a programming interface that allows JavaScript to access, read, change, add, and delete HTML elements on a webpage.

What are Nodes?
Iska matlab hai ke HTML document ke different parts ko Nodes kaha jata hai.
Node	Meaning
Document	Poora HTML document
Element Node	HTML tag, jaise h1, p, body
Attribute Node	HTML attribute, jaise id, href
Text Node	Element ke andar likha hua text

What is DOM API?
DOM API methods aur properties ka collection hai jo JavaScript ko HTML webpage ke content, structure aur styling ko control karne ki facility deta hai.

Method (Action)
Method ek function hota hai jo kisi object ke through koi kaam (Action) perform karta hai.

Property (Value)
Property kisi HTML element ki information ya value hoti hai. Iski value hum read bhi kar sakte hain aur change bhi.

API Methods and Properties
JavaScript mein document aur window jaise global objects hote hain jo browser APIs tak access provide karte hain.

Method vs Window
Method	Window
Action perform karta hai	Browser window ko represent karta hai

appendChild()
Kisi parent element ke andar child element add karta hai.
