Function syntax:
- function name(){
      console.log("Any thing you want to print");
  }
  name();

- function — JavaScript ka keyword hai jo function banata hai.
- name — function ka naam kay h.
- () — function ke naam ke baad likhe jate hain parentheses.
- {} — Curly brackets ke andar function ka code hota hai.
- name() — function ko call karta hai, yani uska code chalata hai.

1. Function kya hota hai?
Function code ka aik block hota hai jo kisi specific kaam ko perform karta hai aur jise hum baar-baar use kar sakte hain.

2. Function ko Call ya Invoke karna kay hota h.
Function ke code ko chalane ke liye usay call ya invoke karna hota hai.

Functions ki madad se hum:
- Code ko organize kar sakte hain.
- Repeated code ko kam kar sakte hain.
- Code ko samajhna aur maintain karna aasaan bana sakte hain.
- Kisi specific task ko alag function mein rakh sakte hain.

3. Function Parameters kya hote hain?
Parameters woh variables hote hain jin ke zariye hum function ko values provide karte hain.
Arguments Woh actual values hain jo function ko call karte waqt di jati hain.

4. Function Return Values: return statement function se result wapas deta hai, jise hum variable mein store karke ya kisi doosri calculation mein use kar sakte hain.

- return: Function se value wapas deta hai, jise hum aage code mein use kar sakte hain.
- console.log(): Console mein value display karta hai, lekin khud value return nahi karta.

5. Function Expression ka matlab hai ke hum function ko ek variable ke andar store karte hain.

6. Arrow Function JavaScript mein function likhne ka short aur modern tareeqa hai. Is mein hum function keyword ki jagah => (arrow) use karte hain.

- function keyword: Arrow Function mein function ki jagah => use karte hain.
- return keyword: Single expression mein return skip kar sakte hain.
- curly brackets {}: Single expression mein curly brackets skip kar sakte hain.

7. Callback Function: A callback function is a function passed as an argument to another function and executed inside that function.
